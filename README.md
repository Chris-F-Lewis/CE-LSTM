This repository is used for data publication for "A CE-LSTM Method for Electromagnetic Interference Anomaly Detection and Recovery of UAV Flight Data". 

**Dataset Details**

The datasets include:

**Raw Data**: Original data without injected anomalies, representing normal operating conditions. Suitable for training baseline models or as health state references.

**Simulation Anomaly Data:** Simulation datasets organized by fault types, covering various fault modes used in experiments. Data are categorized into subfolders according to fault types (e.g., bearing fault, gear fault, imbalance, etc.). Each fault category may contain multiple operating conditions (e.g., load, speed) and severity levels.

**Real-world Data (upcoming):** We plan to release actual fault data collected from physical equipment in the future, corresponding to the fault types in simulation data to validate algorithms in real-world scenarios.

**Engineering Files (upcoming):** Future releases will include simulation model source files (e.g., Simulink, AMESim), data preprocessing scripts (Python/MATLAB), and experimental configuration parameters.
